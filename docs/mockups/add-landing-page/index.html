Specs, architecture and code. In sync at each step.

sparc is a Claude Code plugin for spec-driven work with agents. A team of five roles takes each idea from a spark to a reviewed and tested change. The specs, the decisions and the documents agree with the code.

Install with the Claude Code CLI 
$ claude plugin marketplace add vensas/sparc
$ claude plugin install sparc@sparc

Read the source on GitHub See how a change works

1.0

One loop for each change

Agents write code fast, but the specs and documents fall behind. In sparc, each feature or fix goes through the same steps. Running apply approves the change, so you do not type an approval.

  1. Propose

    /sparc:propose

    Proposal, specs, design, tasks and mockups.

    Product owner, architect, UX designer

  2. Apply

    /sparc:apply

    Tests first, then the code for each task.

    Software engineer

  3. Review

    Fresh context

    A reviewer without the session history reads the diff.

    Software engineer

  4. QA

    qa.md

    An automated test for each spec scenario.

    QA engineer

  5. Verify

    Stop hook

    Lint, tests and evidence must pass before the agent can stop.

    Verifier, no LLM

  6. Archive

    /sparc:archive

    Specs, changelog, backlog, C4 and canvas in sync.

    Product owner, architect

  7. Release

    /sparc:release

    Version, changelog and tag with Conventional Commits.

    You

sparc adds the roles, the document set and two checks on top of OpenSpec.

2.0

Five roles, one owner for each document

A role is a rule file that a skill follows. Each role owns its documents, so each fact has one home.

RoleDoesOwns
Product ownerWrites testable requirements. Accepts the change from the QA report.docs/backlog.md, proposal, specs
ArchitectDesigns the simplest structure. Writes decisions with their options.README, C4, canvas, ADRs, design, tasks
UX designerValidates an interface with static mockups first.docs/mockups/
Software engineerImplements test first. Reviews the change in a fresh context.Code and tests
QA engineerProves each spec scenario with an automated test.qa.md

5.0

Install and start a project

Prerequisites: Claude Code, Node.js 20 or later, git and OpenSpec.

  1. Install OpenSpec.

    npm install -g @fission-ai/openspec

  2. Add the marketplace and install sparc. In Claude Desktop, use Plugins, then Add from repo.

    claude plugin marketplace add vensas/sparc
claude plugin install sparc@sparc

  3. Open the folder of your project and tell the idea one time.

    /sparc:init <project idea>

  4. Propose each feature or fix. Then apply and archive it.

    /sparc:propose <feature>
