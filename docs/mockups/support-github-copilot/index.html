A plugin for coding agents on OpenSpec. Five roles take each idea to a reviewed and tested change.

Install

Claude Code

$ npm install -g @fission-ai/openspec
$ claude plugin marketplace add vensas/sparc
$ claude plugin install sparc@sparc

GitHub Copilot CLI

$ npm install -g @fission-ai/openspec
$ copilot plugin marketplace add vensas/sparc
$ copilot plugin install sparc@sparc

1.0

One loop for each change

Running apply approves the change.

  1. Propose

    /sparc:propose

    Proposal, specs, design and tasks.

    Stops: Decisions get lost.

    Product owner, architect, UX designer

  2. Apply

    /sparc:apply

    Tests first, then the code.

    Stops: The agent guesses.

    Software engineer

  3. Review

    qa.md

    A fresh agent reads the diff.

    Stops: The agent reviews its own work.

    Software engineer

  4. QA

    qa.md

    A test for each scenario.

    Stops: No test proves the spec.

    QA engineer

  5. Verify

    hooks/hooks.json

    Lint, tests and evidence must pass.

    Stops: "Done" without proof.

    Verifier, no LLM

  6. Archive

    /sparc:archive

    Specs and documents in sync.

    Stops: Documents drift from the code.

    Product owner, architect

  7. Release

    /sparc:release

    Version, changelog and tag.

    Stops: Version and changelog disagree.

    You

Questions

Which coding agents does sparc support?

Claude Code (CLI and Claude Desktop) and GitHub Copilot CLI. The README lists what is not tested with Copilot, for example Copilot in VS Code and the cloud agent: Supported Agents.

Can I use sparc in an existing code base?

Yes. Run /sparc:init in the folder of the project. The architect documents what it finds in the code.

Must a small fix go through the full loop?

Yes. Each change of behavior goes through propose, apply and archive. This is the cost of specs and documents that stay correct.

Does sparc work with pull requests?

Yes. Choose the workflow trunk or pull-request in openspec/config.yaml. In the pull request workflow, the review or the merge is the approval.

5.0

Start a project

In Claude Desktop, add sparc with Plugins, then Add from repo.

  1. Open the folder of your project. Tell the idea one time.

    /sparc:init <project idea>

  2. Propose each feature or fix. Then apply and archive it.

    /sparc:propose <feature>
