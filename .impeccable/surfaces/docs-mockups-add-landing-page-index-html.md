Scope: sparc landing page with imprint and privacy policy (website/, mockup in docs/mockups/add-landing-page/). Mode: Persuade.
Audience: tech leads and architects who choose how a team works with coding agents. Action: install sparc (commands), or read on GitHub.
Proof: sparc's own repository history (ADRs, archived changes, releases). No invented claims.
Constraints: minimal; logo and purple/gold pinned; EN/DE/FR; no cookies, no external requests; WCAG 2.2 AA.

## Direction contract

THESIS: sparc is a fixed document set and a disciplined loop, so the page is the standards manual of that way of working. It refuses the dark dev-tool page with a glowing terminal hero and a row of feature cards.

OWN-WORLD: A technical drawing sheet. White sheet (dark: #0f0c14) with a faint 24px drawing grid in the first viewport, ink #16121c, purple #552583 (dark #b08be0) only for a 4px top rule, links, section addresses and the title block head. Gold #fdb927 only in the logo spark and as a 4px bar on the active loop step. Archivo self-hosted, semi-condensed bold for headings, regular for body. Hairline rules, strict 12-column grid, ruled spec tables, a drawing title block with the product facts. Light or dark from prefers-color-scheme.

STORY: The visitor sees the pains (documents fall behind, done without proof, self-review bias, lost decisions, guesses, a process for each project) next to what sparc does about each, then the loop, the roles and documents, the proof in sparc's own repository, the FAQ, and installs.

FIRST VIEWPORT: Sheet with the drawing grid: logo top-left, nav as a manual index top-right. Left 7 columns: a heading at about 3.75rem, one sentence, the install command in a ruled block with a copy button, and a GitHub link. Right 4 columns: the title block (type, built on, formats, requires, version, license). Below, the change loop starts as a strip of seven ruled frames.

FORM: Standards Manual, position 3 of my ordered list, assigned by the roll. seed:a185d325cb0f9092. Raises: numbered addresses (teletext); every block ruled and framed (anime command center); loop as strict frames with the active frame lit gold (film); proof in one ranked row (kiln); a complete billing block footer (exploitation sheet); the next step marked before it happens (algorave). Signature interaction: the loop frames step through on scroll, the active frame marked with a gold bar, the next frame outlined; reduced motion shows all frames static.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
