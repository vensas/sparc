Scope: sparc landing page with imprint and privacy policy (website/, mockup in docs/mockups/add-landing-page/). Mode: Persuade.
Audience: tech leads and architects who choose how a team works with coding agents. Action: install sparc (commands), or read on GitHub.
Proof: sparc's own repository history (ADRs, archived changes, releases). No invented claims.
Constraints: minimal; logo and purple/gold pinned; EN/DE/FR; no cookies, no external requests; WCAG 2.2 AA.

## Direction contract

THESIS: sparc is a fixed document set and a disciplined loop, so the page is the standards manual of that way of working. It refuses the dark dev-tool page with a glowing terminal hero and a row of feature cards.

OWN-WORLD: White sheet, ink #16121c, purple #552583 as full-width fields that own regions (dark theme: #1a1028 field, #b08be0 type), gold #fdb927 only for the spark and the active step. Archivo self-hosted, semi-condensed heavy for display, regular for body. Hairline rules, strict 12-column grid, ruled spec tables, manual-style addresses (1.0, 2.0) in the navigation.

STORY: The visitor sees the problem (docs fall behind agents), sees the loop that fixes it, sees the roles and documents, checks the proof in sparc's own repository, and installs.

FIRST VIEWPORT: Purple field across the top ~60%: logo top-left, nav as a manual index top-right, a display headline at 5–6rem, one sentence, the install command in a ruled block with a copy button, and a GitHub link. The spark sits gold at the field's top-right corner, breaking the frame. Below the field, the change loop starts as a strip of seven ruled frames.

Signature interaction: the loop frames step through on scroll, the active frame lit gold, the next frame outlined; reduced motion shows all frames static.
