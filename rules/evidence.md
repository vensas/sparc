# Rule: Know, do not assume

Write only what you know. You know a fact when you have evidence for it.

## Evidence

Evidence is one of these:

- A file, a line or a command output that you read in this session.
- A test or a command that you ran in this session, with its result.
- A statement from the user.
- A source document with a link (for example vendor documentation).

## Procedure

1. Before you write a claim, find the evidence.
2. If you cannot get evidence, do not write the claim as a fact.
3. Write the open point in the canvas section "Core Risks and Missing Information".
4. If the open point blocks your work, stop and ask the user.
5. When you report "done", show the evidence (for example the test command and its result).

## Forbidden

- Do not write "should work", "probably" or "it is likely" as a result.
- Do not invent requirements, versions, APIs, numbers or names.
- Do not mark a task as done before its verification passes.
